# eYRC Khoj-o-Drone

ROS 2 Humble and Gazebo project files for the e-Yantra Khoj-o-Drone tasks.

## Repository contents

- `swift_pico/`, `swift_pico_description/`, and `controller_tuner/` contain the existing Task 1A–1C project files.
- [`FINAL_SUBMISSION/Task2B_submission_20261019.zip`](FINAL_SUBMISSION/Task2B_submission_20261019.zip) is the Task 2B submission bundle. It contains the required `KD__pico_client.py`, `KD__pico_server.py`, and `KD__waypoint_service.py` scripts, the waypoint action and service definitions, the recording and its metadata, and supporting source files.

## Task 2B result

The included recording is from a local run with rosbag started before the service and controller. The four waypoint actions completed in 33.31 seconds in that run. This is a local simulation result; an official e-Yantra evaluation is needed to confirm the score.

The ZIP is the submission artifact. Extract it when you need the Task 2B files; the ROS workspace and trial outputs are not duplicated elsewhere in this repository.
